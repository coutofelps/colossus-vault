# Glossário

Termos do domínio usados no código, specs e decisões.

| Termo | Definição |
|---|---|
| **Leilão** | Listagem com prazo definido onde o maior lance vence |
| **Lance** | Oferta feita por um comprador em um leilão ativo |
| **Preço de reserva** | Valor mínimo que o vendedor aceita (pode ser oculto ao comprador) |
| **Compre Agora** | Opção de preço fixo que encerra o leilão imediatamente |
| **Lance Proxy** | Lance automático até o valor máximo definido pelo comprador, incrementado conforme necessário |
| **Lote** | Um item único ou conjunto sendo leiloado |
| **Vendedor** | Usuário verificado que anuncia itens para leilão |
| **Comprador** | Usuário que dá lances em leilões |
| **Curadoria** | Processo de revisão e aprovação de itens antes de irem ao ar |

_Adicione termos conforme o domínio evolui._
